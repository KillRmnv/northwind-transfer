# currency-lookup — справочник валют

## Цель
Код валюты — проверяемая ссылка (FK), а не свободная строка. Сид идемпотентен,
строчный код с пробелами резолвится, мусора (`kzt` рядом с `KZT`) в справочнике нет.

## Источник в Java
- `service/currency_contract.feature` (7 кейсов): сид держит коды из ТЗ,
  каждый код проходит CHECK схемы, строчный код резолвится, валюта вне справочника
  отвергается, курс для валюты вне справочника невозможен (FK), учётная валюта
  из конфигурации.
- `service/currency_sweep.feature` (12 кейсов): свип добавляет новый код,
  имеющийся не дублирует, малformed (`US`, `USDD`, `usd`, `12`) пропускает,
  пробелы не мешают, недоступный провайдер не трогает справочник, стартовый
  импорт идемпотентен.
- `api/client_api.feature`: `An unsupported currency is refused, and the
  accepted set is published` (там не должно быть `"kzt"`).

## Кейсы (вход → ожидание)

| # | Вход | Ожидание |
|---|------|----------|
| 1 | Сид из `currencies.json` (10 кодов) | все в lookup, все заглавные, `UNIQUE(code)` |
| 2 | `POST /quotes` с `rub` / ` eur ` | `200`-путь, валюта резолвится в `RUB`/`EUR`, дубль не создаётся |
| 3 | Валюта вне справочника (`XXX`) | `VALIDATION_ERROR`/`UNSUPPORTED_DIRECTION`, отказ называет код |
| 4 | INSERT курса для валюты вне lookup | отказ FK на уровне схемы |
| 5 | Сид повторным прогоном | `ON CONFLICT DO NOTHING`, дублей нет |
| 6 | Импорт публикует новый код (`ZWL`) | добавлен один раз |
| 7 | Импорт публикует мусор (`US`, `USDD`, `usd`, `12`, `KZT1`, `U S`) | пропущен, счётчик не растёт |
| 8 | Импорт публикует `" ZWL "` | добавлен как `ZWL` |
| 9 | Провайдер недоступен при импорте | lookup не тронут, только лог |
| 10 | Переименование кода (деноминация) | только миграцией `UPDATE CASCADE` (A12) |

## Адаптация под наш контракт
- PK справочника — естественный код `VARCHAR(3)` (D17), FK из 8+ таблиц (D16).
- Валидация регистра — в API на входе (A12); регистр в `currencies.json` уже верхний.
- У нас нет ручки `/currency-pairs`: «отслеживаемое множество» = направления
  из `tariffs.json`; кейсы `currency_pairs.feature` про трекинг не портируем.
- Ошибка — RFC 9457 + `error.code`, `Content-Type: application/problem+json` (A11).
